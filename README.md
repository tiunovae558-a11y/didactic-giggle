# 💙 METROSHOP

Telegram-магазин с оплатой Telegram Stars.

## Возможности

- 🌐 Каталог сайтов
- 📱 Каталог аккаунтов
- 🎁 Каталог подарков
- ⭐ Оплата Telegram Stars
- 🔒 Проверка подписки на канал
- 👑 Административная панель
- 📦 Сохранение заказов

## Запуск

1. Установите зависимости:
   pip install -r requirements.txt

2. Настройте переменные окружения:
   BOT_TOKEN
   ADMIN_IDS
   CHANNEL_ID
   CHANNEL_URL

3. Запустите:
   python bot.py
